# 2026-10-10 工作记录

## 二期 Module 1 收尾 + 苹果生成（路A）

### 果园渲染崩溃排查（虚拟机 Gazebo）
- 根因两层：(1) 虚拟显卡 3D 加速不足导致 OGRE px=0 断言崩溃；(2) `GAZEBO_RESOURCE_PATH` 未设置 → shader lib 找不到 → scene 初始化失败。
- 解决：`.bashrc` 加 `source /usr/share/gazebo/setup.bash` + `export GAZEBO_RESOURCE_PATH=/usr/share/gazebo-11:$GAZEBO_RESOURCE_PATH`，以及软渲染 `LIBGL_ALWAYS_SOFTWARE=1` / `QT_QPA_PLATFORM=xcb`。
- 顺序陷阱：gazebo 资源导出必须写在 ROS/工作空间 source 之后，否则被 ament env hook 覆盖。

### 树不显示
- 原因：`model://tree_model` 的 include 在 world 内加载时强制要求目录内有 `model.config`。补 `tree_model/model.config` 与 `apple_model/model.config` 即可。

### 苹果生成（路A 完成）
- 新建 `scripts/spawn_apples.py`：ROS2 节点，等待 `/spawn_entity` 后，按 9 棵树坐标 + 每树 3 个树冠偏移（z≈1.42~1.62，树冠中心 1.55）批量 spawn 27 个动态苹果，实体名 `apple_01..27`。
